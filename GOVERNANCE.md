# Governance

This document describes how BlackScholesLab is governed. It reflects the
current state of the project honestly and may evolve as the community grows.

## Current maintainer

Amrut Deshmukh is the creator and current primary maintainer of
BlackScholesLab.

## Decision making

Decisions are documented through public issues and pull requests. Proposals,
design choices, and mathematical conventions are discussed openly so that
reasoning is available to contributors and users.

## Priorities

- **Mathematical correctness and reproducibility** take priority over feature
  speed. A calculation is not considered done until it is tested against an
  independent reference with documented tolerances.
- Transparent and explicit behaviour is preferred over convenient but opaque
  shortcuts.

## Contribution review

Contributions are reviewed on technical merit. Reviews consider correctness,
clarity, tests, documentation, and consistency with the project's design
principles. Constructive, respectful feedback is expected from all
participants.

## Evolution of governance

This governance model is minimal by necessity: the project currently has a
single maintainer and no formal contributors. Governance may evolve when
genuine contributors join, and any changes will be made through public
discussion and documented in this file.

## No fabricated roles

This document names only the maintainer who actually created the project. No
additional maintainers, contributors, or organisations are implied to exist.
