# Security Policy

## Supported versions

**No stable release currently exists.** The project is in early development
(versions `0.1.0.dev0` and below). Because nothing has been released, there
are no published versions receiving security updates at this time. Security
support for released versions will be documented here once the first stable
release is published.

## Reporting a vulnerability

If you discover a security vulnerability, please report it **privately**. Do
not disclose it publicly before a fix is available.

Preferred method:

- Use GitHub private vulnerability reporting for this repository, if enabled:
  open a security advisory from the repository's "Security" tab.

If GitHub private vulnerability reporting is unavailable, contact the maintainer
privately through the repository profile. Do not post vulnerability details in
public issues or discussions.

## Public disclosure

Please do not publish details of a suspected vulnerability in a public issue,
pull request, or discussion until a fix has been released or the maintainer has
explicitly approved disclosure. Responsible disclosure helps protect users.

## Scope

This policy covers the BlackScholesLab source code and distribution. It does
not cover third-party dependencies; those should be reported to their
respective maintainers.

## Note on credentials

This project does not handle user credentials, brokerage accounts, or live
market data. There is no secret storage or authentication layer in the planned
design.
